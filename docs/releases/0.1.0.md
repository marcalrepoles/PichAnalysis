# PichAnalysis 0.1.0

First installable Windows x86_64 release of the PichAnalysis desktop app.
It includes project import and mapping, Presence/Absence, Gene Ontology,
KEGG, Reactome, MitoCarta, InterPro/Pfam, STRING, Complexes, mtDNA Evidence,
Proteomics QC, Differential Preparation and Statistics, Cross-module
Explorer navigation, and offline Consolidated Reports in HTML/PDF.

The Windows installer includes Python, PySide6/Qt and application-owned R
scripts. R and required R packages are external dependencies; local
scientific databases are managed separately and not bundled. Release
preflight reports missing runtime dependencies without installing them.

Known limitations: the Windows build is unsigned; macOS build and runtime
have not been validated on macOS hardware; the full real STRING acquisition
smoke was not executed during final hardening. No clean-machine certification
is claimed from the controlled installation test on the current Windows host.
See `installation-windows.md` and `runtime-dependencies.md`.
